# Playwright Book — UI Automation Tests

Учебный проект по автоматизации тестирования веб-приложений с использованием
**Python, Pytest и Playwright**.

Проект предназначен для практики UI-тестирования, построения автотестов,
работы с браузерами и организации тестового проекта.

---

## 🛠 Стек проекта

### Python

**Python 3.10+**

Основной язык программирования проекта.

Используется для:
- написания автотестов;
- работы с тестовыми данными;
- реализации вспомогательных функций;
- организации тестовой логики.

---

### Pytest

**Pytest 9.x**

Тестовый фреймворк для запуска и организации автоматизированных тестов.

Используется для:
- запуска тестов;
- assertions;
- fixtures;
- параметризации;
- группировки тестов;
- формирования тестовых отчётов.

```python
def test_example():
    assert 1 + 1 == 2
